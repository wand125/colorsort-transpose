Format of a move sequence

手順の書式

Lanes are numbered 0 to N; lane 0 is the one that starts empty. A move is two characters in base 36 (0–9, then a–z): the lane the ball leaves and the lane it enters. A sequence is the moves written one after another. The four-colour solution starts with 10: the top ball of lane 1 goes to lane 0.

レーンには 0 から N の番号を付ける。レーン 0 が最初に空のレーン。1 手は 36 進（0–9、a–z）の 2 文字で、玉が出るレーンと入るレーンを表す。手順はそれを並べた文字列。4 色の手順 の最初の 10 は、レーン 1 の一番上の玉をレーン 0 へ移す手。

The sequences below are in a normal form, so that solutions which differ only by renaming lanes 1 to N, or by swapping moves that use disjoint lanes, are written the same way: the lanes are renamed so that the finished colours appear in increasing order from left to right, and independent moves are put in lexicographic order.

下の手順は正規形で書いてある。レーン 1〜N の番号の付け方だけが違う手順や、使うレーンが重ならない手の順番だけが違う手順は、同じ書き方になる。完成時に色が左から番号順に並ぶようにレーンの番号を付け替え、互いに関係のない手は辞書順に並べている。

Check it yourself

自分で確かめる

Replaying a sequence needs no special tool. This is the whole check, in Python:

手順の再生に特別な道具は要らない。確認は、Python で書くと次のとおり。

D = "0123456789abcdefghijklmnopqrstuvwxyz"
def check(n, s):
    lanes = [[]] + [list(range(1, n + 1)) for _ in range(n)]
    for i in range(0, len(s), 2):
        a, b = D.index(s[i]), D.index(s[i + 1])
        assert a != b and lanes[a] and len(lanes[b]) < n
        lanes[b].append(lanes[a].pop())
    return all(not l or (len(l) == n and len(set(l)) == 1) for l in lanes)

In the repository, python3 tools/verify_all.py replays every stored sequence and compares the move counts with bounds.tsv. The lower-bound searches are in lowerbound/ (Rust):

リポジトリでは、python3 tools/verify_all.py が保存した手順をすべて再生し、手数を bounds.tsv と突き合わせる。下界の探索は lowerbound/（Rust）にある。

cd lowerbound && cargo build --release
COLORLB_JOINT=1 ./target/release/colorlb check 4      # bound J vs exact distance, all states, N = 4
COLORLB_JOINT=1 ./target/release/colorlb prove 6 55   # no solution with at most 54 moves
